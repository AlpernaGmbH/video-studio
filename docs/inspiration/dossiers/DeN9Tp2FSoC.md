**Beispiele für die Sätze (in eigenen Worten):** *Layered Single*: ein Stück einer anderen Person im Vordergrund, so sieht man, wem das Gegenüber zuhört. *Top-Down*: gerade von oben für Hände, Essen, Produkte, Anordnungen. *Reaction Frame*: wie jemand auf das gerade Geschehene antwortet, der Ausdruck zeigt, was es bedeutet. *Insert Shot*: ein Detail aus der Handlung herauslösen (Handy, Hand, Schlüssel), damit Wichtiges leicht erkannt wird. *Rack Focus*: Schärfe von einem Objekt zum anderen verschieben, ohne zu schneiden. *Pull Out*: sich vom Motiv entfernen, um die Umgebung zu zeigen oder es klein wirken zu lassen. *Slow Move In*: langsam auf den Ausdruck zugehen, Erkenntnis oder Spannung.
